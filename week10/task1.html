Deployment checklist

  • All file paths are relative.
  • File names are lowercase (GitHub's servers are case-sensitive).
  • No debug console.log() calls left.
  • No API keys, passwords or tokens in the public repo.
  • index.html is in the repo root.
  • Tested the live URL in a private window.
