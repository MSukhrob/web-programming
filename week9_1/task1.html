accessibility fixes (homework)

  1. skip link: keyboard users can jump over the menu to the main content. 
    <a class="skip-link" href="#main">skip to main content</a>
  2. alt text: the picture now describes its purpose. 
    before: <img src="team.png">
after:  <img src="team.png" alt="three students working on laptops">
  3. form labels: every input has a real label connected with for and id. 
    before: <input placeholder="email">
after:  <label for="email">email address</label>
        <input id="email" type="email">
  4. real buttons: a clickable div was replaced with a button that works with tab, enter and space. 
    before: <div class="btn" onclick="...">show details</div>
after:  <button type="button" aria-expanded="false">show details</button>
  5. colour contrast: light grey text was changed to dark slate (ratio above 4.5:1). 
    before: color: #94a3b8;
after:  color: #334155;
