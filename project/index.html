About Komorebi

Komorebi (木漏れ日 — sunlight filtering through leaves) is a full-stack web application built for Web Programming (K0126002) by Sukhrob Mansurov (202537508).

  • Watchlist & Progress: Organize titles as Planned, Watching, or Watched, track seasons/episodes with Next Episode actions, rate 1–10 stars, and write reviews.
  • Discovery & Radar: Real-time TMDB search (/ or Ctrl+K), browse by genre/rating, Release Radar, and Film & TV news feeds.
  • Social & Privacy: Public, Friends-only, or Private profiles (/u/<username>), friend requests, and friend activity feeds.
  • Stats & Export: Personal watch-hour charts, rating breakdowns, and one-click CSV/JSON export.
Node.js Express 5 PostgreSQL TMDB API HTML5 & CSS3 Vanilla JS
