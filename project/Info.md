## Overview

**Komorebi** is a full-stack web application for tracking movies, series, and cartoons (*Planned*, *Watching*, *Watched*), rating and reviewing titles, tracking episode progress, viewing personal statistics, and sharing watchlists with friends.

**Tech Stack:** Node.js, Express 5, PostgreSQL, TMDB API, HTML5, CSS3, Vanilla JavaScript.
