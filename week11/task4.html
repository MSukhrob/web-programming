Homework Specifications

Build a modular React portfolio gallery consisting of three structured components:

  • ProjectCard (title, description, tech stack array, GitHub link, demo link).
  • ProjectList that renders an array of projects with stable unique keys.
  • FilterBar that dynamically computes technology tags and allows the user to filter the list.

Component Structure & Code

// 1. FilterBar.jsx
function FilterBar({ techs, selected, onSelect }) {
  return (
    <div className="filter-bar">
      {techs.map(t => (
        <button
          key={t}
          className={t === selected ? 'filter-pill active' : 'filter-pill'}
          onClick={() => onSelect(t)}
        >
          {t}
        </button>
      ))}
    </div>
  );
}

// 2. ProjectCard.jsx
function ProjectCard({ title, description, tech, github, demo }) {
  return (
    <article className="project-card">
      <h3>{title}</h3>
      <p>{description}</p>
      <ul className="tech-pill-list">
        {tech.map(t => <li key={t} className="tech-pill">{t}</li>)}
      </ul>
      <div className="project-actions">
        <a href={demo} target="_blank" rel="noopener" className="live-btn">Live Demo →</a>
        <a href={github} target="_blank" rel="noopener" className="gh-btn">Source </a>
      </div>
    </article>
  );
}
