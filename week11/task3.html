Challenge Specifications

Build a ProductCard component that accepts: name (string), price (number in KRW), rating (0 to 5 stars), and inStock (boolean).

  • Bonus 1: Display rating formatted as rating / 5 stars alongside visual star icons (★★★★½).
  • Bonus 2: Conditionally display "In Stock" (green) or "Out of Stock" (red badge) and apply sold-out opacity dimming to unavailable products.
  • Korean Won Price: Formatted with thousands separators using price.toLocaleString('ko-KR') + '원'.

Interactive Product Catalog

Test real-time React state: filter products, or click "Toggle Stock Status" on any card to watch React conditionally re-render the badges and opacity.

// ProductCard.jsx
function ProductCard({ name, price, rating, inStock, onToggleStock }) {
  // Bonus 1: Calculate star icons based on rating
  const filled = Math.round(rating);
  const stars = '★'.repeat(filled) + '☆'.repeat(5 - filled);

  return (
    <div className={inStock ? 'product-card' : 'product-card sold-out'}>
      <h3>{name}</h3>
      <p className="product-price">{price.toLocaleString('ko-KR')}원</p>

      <div className="product-rating">
        <span className="stars-icon">{stars}</span>
        <span>{rating} / 5 stars</span>
      </div>

      {/* Bonus 2: Conditional Stock Badge */}
      <span className={inStock ? 'stock-badge in-stock' : 'stock-badge out-of-stock'}>
        {inStock ? '✓ In Stock' : '✕ Out of Stock'}
      </span>

      <button className="toggle-stock-btn" onClick={onToggleStock}>
        Toggle Stock Status
      </button>
    </div>
  );
}
